# StudySprint — HCIN6222 Part 3 Final POE Prototype

StudySprint is a responsive student assignment-planning prototype built with HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP folder.
2. Open `website/index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
3. Add an assignment, due date and optional task checklist.
4. Test task checkboxes, adding tasks, editing/deleting assignments, progress feedback and the focus timer.
5. Refresh the page to confirm that assignment data remains in the same browser.

## Improvements in this final iteration
- Assignment data saved with browser `localStorage`.
- Edit and delete controls, with a confirmation dialog for deletion.
- Add tasks to existing checklists and update progress automatically.
- Required-field validation and due-date minimum.
- Keyboard skip link, visible focus styles, labels, live status messages and responsive layouts.
- Reduced-motion preference support and more explicit privacy note about browser-only storage.

## Limitations
This is still a front-end student prototype. Data is stored only in the current browser/device and is not synchronised or backed up. It has no real account/login, cloud database, notifications, or peer collaboration. A formal WCAG audit and testing with representative users and assistive technologies have not been completed.
